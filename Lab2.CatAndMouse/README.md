# Lab2.CatAndMouse

Консольная игра «Кошка и мышь» на C#. Программа читает команды из файла теста, моделирует перемещения игроков по циклическому игровому полю и записывает ход игры в файл журнала.

## Запуск

Откройте `CatAndMouse.sln` в Visual Studio или соберите проект через .NET SDK. При запуске программа попросит ввести номер теста: `1`, `2`, `3` или `4`.

## Формат входных данных

Входной файл называется `<номер>.ChaseData.txt`. В первой строке указывается положительный размер игрового поля. Далее идут команды перемещения игроков. Каждая команда содержит букву игрока и целое число шагов.

## Команды

- `M n` — переместить мышь на `n` шагов.
- `C n` — переместить кошку на `n` шагов.
- `P` — записать текущие позиции и расстояние между игроками в журнал.

Поле циклическое: при выходе за его границы игрок появляется с противоположной стороны.
